
Das bedeutet: Compose baut die App lokal aus dem Quellcode. Maven ist trotzdem nicht auf dem Host nötig, weil Maven im `Dockerfile`-Build-Container läuft.

Wenn die App zukünftig direkt aus Docker Hub kommen soll, ändere den Service auf:

```yaml
app:
  image: rochdi1/jwt-security-api:latest
  container_name: springboot_auth_api
  ports:
    - "8080:8080"
```

Dann entfernst du dort den gesamten `build:`-Abschnitt und startest mit:

```bash
docker compose pull
docker compose up -d
```

Maven brauchst du nur, wenn du die Anwendung außerhalb von Docker lokal kompilieren möchtest.
